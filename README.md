# Kelime Bulmaca - Görseller

Bu repo, Kelime Bulmaca oyunundaki görsel ipuçlarını ve bayrakları barındırır.

## Klasörler
- `clue-images/` - normal görsel ipuçları (Excel'de Tip=2)
- `flags/` - ülke bayrakları (Excel'de Tip=3)

## Görsel eklemek
1. Görseli ilgili klasöre yükleyin (GitHub web arayüzünden "Add file > Upload files")
2. Yüklenen dosyaya tıklayıp **"Raw"** butonuna basın - açılan sayfanın adres
   çubuğundaki link, Excel'e yapıştıracağınız link
3. Link şu formatta olacak:
   `https://raw.githubusercontent.com/zgonejko/kelime-bulmaca-gorseller/main/clue-images/DOSYAADI.png`

## Görsel özellikleri
- Format: PNG (şeffaf/düz arkaplan) veya JPG
- Boyut: kare (1:1), ~300x300px yeterli
- Arkaplan rengi: #D1F2C7 (oyundaki soru hücresi rengiyle aynı)
